# Rachika — Rachit ❤️ Nishika

A 7-page romantic interactive website made for Nishika.

## Pages
1. Welcome — Rachit ❤️ Nishika / #Rachika
2. First I Love You — chat + animated GIF + love letter
3. The Girl I Adore — scratch-to-reveal photo cards
4. Little Things — cute chat memories + butterfly/flower/petal effects
5. Just Us — cute memes + couple illustrations
6. Our Little Challenge — interactive #Rachika tile puzzle + first Ludo memory
7. My Pillow — final love letter + Nishika ending photo

## Run
Open `index.html` in a browser. No backend is required.

## GitHub Pages
Upload the entire folder/repository. In GitHub: Settings → Pages → Deploy from branch → choose `main` and `/ (root)`.

All image assets are local, so the website does not depend on image hosting.

## Background Music
The website includes the uploaded instrumental as `assets/music/rachika-love-beat.mp3`.
Use the floating **♫ / 🔇** button in the top-right to play or pause it. Browsers may block
automatic sound until the first user interaction; after enabling it, the preference is stored
in the browser.
